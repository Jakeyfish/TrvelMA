# Web 横向编辑工作台

Web构建标识：20261110-ui-v2。已提交代码184f679，并通过Cloudflare生产部署上线；详见web-ui-release.md。

## 结构

- 行程新增、编辑、复制：宽屏三栏。左侧为类型、智能输入、来源和客户；中间为日期、路线、停靠点与航班；右侧为费用、状态及提醒。保留同一个form、字段名称、提交控制器、隐藏快照与表单外保存按钮。各栏只在内容溢出时独立滚动，顶部取消/保存始终可见。
- 智能输入用原生details折叠，保留原文字、输入框、识别入口与反馈；没有折叠必填项。
- 客户新增/编辑：基本资料、联系方式、常用地址三栏，备注随地址放在末尾。动态添加/删除、默认联系方式/地址的原处理器不变。
- 结算：行程/车费与小费、费用明细分为左右两栏；净收入与取消/仅保存/结算固定在底部，长费用列表不遮住操作。
- 旅行社：较宽的双列表单；短表单不强行撑满屏幕。
- 行程详情：基本信息与航班/财务分左右容器，保留两个机场和航站楼、刷新航班及原有业务操作。客户详情同步使用宽版分区。
- 宽屏阈值1050px；平板采用双栏且不限制每列高度；手机恢复自然单列滚动。没有为视觉顺序强行修改tabindex。其他页面延续workspace.css的新配色和组件样式，不替换账号、同步或数据服务。
