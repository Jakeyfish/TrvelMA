# 1.1 本地只读与导出入口

分支 codex/billing-1.1，版本 1.1(14)。本轮不启用收费，不改变生产数据库或云端授权。

## 实现

- RootView 在本地使用门禁启用时挂载 LocalAccountWorkspace，先准备当前账号的本地资料归属，再读取权益。正常编辑界面只在明确允许时挂载；凭据不明显示只读/重试/恢复购买，确认是新用户才可能显示版本购买入口。
- 前台重新核验保留已有编辑页并暂时禁止交互，不因加载中销毁草稿。切换账号或存储模式后丢弃旧请求结果。购买页继续由 RootView 持有，关闭后触发本地重查。监听已验证本地交易更新，合并核验期间重复请求，避免漏掉前台批准/退款事件。
- LocalAccountArchive 按当前本地 scope 获取行程、客户、旅行社，联系方式和地址也校验 scope 及客户归属。使用显式业务字段列表，不导出 LoginInfo、LocalAccount、密码、Token、全部偏好或云端副本。
- JSON 包含行程状态、金额、费用原始 JSON、停靠点、航班快照、提醒、客户/旅行社资料，以及按账号读取的本地名片和收款方式（base64）。不下载远程图片。该文件是资料导出格式，不等于已实现重新导入。
- 只读界面不挂载新增、编辑、结算、删除、同步、航班刷新功能；提供查看、导出、重载、重试、恢复及退出。复用云端导出的 FileDocument；云端过期逻辑不变。
- 新增五条文案及六语言译文；本地 Apple 权益不赋予 Web/云端/航班权限。

## 配置与回退

- localAccessEnforcementEnabled=false、firstPaidLocalBuild=nil，Release 正式购买入口仍关闭。当前正常使用行为保持原样。
- 回退保持门禁关闭即可，或撤回本轮路由和新文件。无模型结构/数据库迁移、无删除数据步骤；历史资料归属采用原有非破坏迁移。
- 启用前必须确定实际收费分界、完成正式历史凭据及升级/重装验收，并验证新只读界面在真机的排版、导出和恢复购买。
