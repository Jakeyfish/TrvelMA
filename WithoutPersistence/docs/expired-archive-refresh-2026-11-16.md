# 到期只读页刷新失败保留已读资料（1.1）

## 已确认原因与边界

真机验收期间到期页出现通用服务器失败提示。代码已确认 load() 在请求前把 snapshot 与 exportData 清空，因此后续失败会把已读资料呈现为0条。此为显示状态丢失的原因，不代表已查明原服务器错误原因，也不代表云端业务数据已删除。

## 最小修复

- 新增纯内存 ExpiredArchiveReadState，集中管理同账号最近一次成功的只读资料和本次请求标识；无落盘缓存、无新服务或数据库变更。
- 同账号开始刷新时保留可见资料；网络暂时错误、HTTP429或5xx失败可保留可见内容，但直到下一次成功前不允许导出。
- HTTP认证/权限错误、不可识别返回等非暂时错误清空资料；成功返回空集合正常替换旧集合，避免旧记录一直残留。
- 账号改变、权限不再适用或视图离开时清空；显示/导出均核对当前账号。请求UUID防止切号、退出后同账号重新进入时旧返回覆盖新状态。
- Supabase设备登记、撤销和RLS校验不变，不以缓存赋予新权限。
- Web loadExpiredArchive 原本在成功后才替换archiveData，没有同样的请求前清空问题，本轮未改Web。复用现有错误文案，无新增语言键。
- AccountArchiveDocument可见性原已有本地导出未提交改动保持原样，没有覆盖。
