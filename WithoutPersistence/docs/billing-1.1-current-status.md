# 1.1 当前发布状态

更新日期：2026-11-10。此文件是1.1状态入口；历史日志中的“待部署”“待本地化”等描述只代表当时状态。

## 已完成

- ASO方案、六语言标题/副标题/关键词/推广文本/描述首段及截图文案已按用户指示纳入1.1。尚未写入App Store Connect，不改变App内显示名称；完整本地化描述和实际截图须在提审前补齐。

- 已合入1.0.1(13)补丁；该正式补丁已提交Apple审核，不等于1.1已提交。
- 1.1默认版本/构建号统一为1.1(14)，Debug和Release一致。本轮以前的1.1(14)构建使用命令行覆盖；现在不覆盖参数也应得到相同版本。
- 本地买断、月付、年付的三个商品已建档，六语言18组商品说明及订阅组六语言已保存；历史核验的148个地区与当时App销售范围一致。正式提审前仍需在线复核商务状态、地区和商品状态。
- 沙盒后端已按授权部署：Apple签名及OCSP校验、交易台账、幂等处理、账号绑定、退款/过期/宽限期和撤销处理。生产收费开关关闭，通知生产地址未设置。
- 本地版不含在线航班查询；购买后禁用重复买断；恢复购买不恢复业务资料，相关说明六语齐全。
- StoreKit本地16项、App376项、Web175项、后端76项已通过；这些结果有各自代码版本及边界，不能替代真实交易验收。最近六语言及编译资源292键通过。
