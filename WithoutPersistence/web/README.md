# 云盛行程管家 Web 版

这是基于现有 Supabase 项目建立的浏览器端应用。它与 iOS 使用同一个 Supabase Auth 账户和数据表；浏览器只包含 Supabase publishable key，业务数据仍由登录 JWT 和数据库 RLS 按账户隔离。

## 本地预览

在 `web` 目录启动任意静态 HTTP 服务器即可，例如：

```sh
python3 -m http.server 4173
```

然后打开 `http://localhost:4173`。浏览器直接打开 `index.html`（`file://`）会因模块和网络安全策略无法工作。

## 当前页面

- 云端邮箱和密码登录、会话刷新、退出
- 总览与行程列表；行程新增、编辑、复制、完成、取消、恢复、结算和软删除
- 行程客户搜索选择、客户常用地址选择、停靠点、路线互换、航班查询与提醒设置
- 客户资料新增、编辑、删除校验、旅行社关联、多联系方式、多地址、备注、快捷拨号/邮件与出行贡献
- 合作旅行社新增、编辑和软删除
- 钱包按天、本周、本月、年汇总收入与费用调整；可维护收款方式、二维码预览与分享
- 名片头像、只读注册资料、昵称、两种样式和多个二维码；名片与收款方式保存到同一云端账户
- 本位币、默认导航和费用项目设置

名片头像、名片二维码和收款二维码使用私有 Supabase Storage。启用图片上传前，先在 Supabase SQL Editor 应用 `supabase/migrations/202610200001_private_account_asset_storage.sql`。旧 Base64 图片会在 Web 首次载入或 iOS 下次同步时复制到 Storage；本机离线副本继续保留。

Web 在每个云端账号的浏览器本地保存一份业务缓存。网络中断时，可继续新增、编辑和软删除客户、旅行社、行程及设置；改动会按操作顺序写入本地队列，恢复网络后自动重放。名片和收款二维码的图片上传也会排队。页面顶部会显示离线或待同步数量；队列中出现服务器拒绝的操作时会保留该项及后续操作，并提示错误。

离线资料和队列保存在浏览器 `localStorage`，清理网站数据或更换浏览器会清除它们；它们不是备份。缓存不保存已下载的云端图片副本，离线首次打开且从未缓存过业务资料时，需要先联网加载一次。请在上线前验证目标浏览器的本地存储配额和恢复流程。

## 云端安全与限制

- 所有数据库请求以用户 JWT 发出，依赖 Supabase RLS；绝不在浏览器放置 service-role key 或航班服务密钥。
- Web 和 iOS 云端航班查询通过已验证登录态的 `variflight-lookup` Edge Function；飞友密钥只存 Supabase Function Secret，函数逐次验证账号权益，并限制每账号每小时 30 次、整个项目每小时 300 次。两条限额迁移已应用，函数已部署，`VARIFLIGHT_API_KEY` 已配置在 Supabase Edge Function Secrets 中。
- 生产部署必须使用 HTTPS，并在 Supabase Auth 的重定向 URL 配置中加入正式 Web 域名。
- 当前 Web 页面界面为简体中文；语言偏好会保存到云端，但尚未驱动整套 Web 界面翻译。
- 浏览器提醒只能在浏览器页面保持打开时触发；页面关闭或浏览器暂停后，不能保证送达。iOS 使用系统本地通知。
- Web 可调用设备定位，但浏览器端目前显示坐标，尚未反向转换成可读地址。客户头像的跨设备图片上传也未实现。
